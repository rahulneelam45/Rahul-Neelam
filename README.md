# Smart Rail

Smart Rail is a GitHub Pages-ready prototype for intelligent Indian train travel.

Features: train search UI, saved/favourite trains, AI-style comparison, delay prediction concept, tracking UI and official-data integration points.

Important: This is NOT IRCTC and does not fake live availability/GPS. Production must use authorised Indian Railways/IRCTC data services for schedules, fares, PNR, availability and running status. Predictions should be labelled estimates.

Official schedule: https://indianrail.gov.in/enquiry/SCHEDULE/TrainSchedule.html
